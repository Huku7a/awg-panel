# AWG Panel

Веб-панель для управления **AmneziaWG** на сервере с нативной установкой AmneziaWG:
просмотр статуса, добавление / удаление клиентов, включение и отключение, QR-коды
и скачивание конфигураций. Поддерживает управление несколькими серверами через
лёгкий агент на каждом узле (модель «как Cockpit»).

Работает поверх уже установленного AmneziaWG: не требует миграции на Docker,
использует тот же файл конфигурации `/etc/amnezia/amneziawg/awg0.conf` и применяет
изменения через `awg syncconf` — без разрыва существующих сессий.

## Возможности

- Список клиентов с состоянием: онлайн / оффлайн / выключен, IP, endpoint, трафик (Rx/Tx)
- Создание клиента: автоматический выбор свободного IP, своя ключевая пара + PSK
- Включение / отключение клиента без потери конфигурации (ключи сохраняются)
- Удаление клиента
- QR-код для AmneziaWG и скачивание `.conf`
- Несколько серверов: центральная панель + агент на каждом VDS (`X-Api-Key`)
- Авто-деплой агента на новый VDS прямо из панели по SSH-кредам (create/пошаговый прогресс в UI)
- Basic-авторизация панели, Bearer-токен агента, авто-бэкап конфига перед изменениями

## Требования

- Сервер Ubuntu/Debian с **root**, где уже установлен и настроен AmneziaWG:
  - `awg`, `awg-quick` в `PATH`
  - конфигурация `/etc/amnezia/amneziawg/<iface>.conf` и `/etc/amnezia/amneziawg/params`
  - (по умолчанию интерфейс `awg0`)
- Python 3.9+ (ставится автоматически/проверяется)
- Порт панели должен быть доступен (скрипт сам открывает его в UFW, если UFW активен)

## Установка панели (одной командой)

```bash
curl -fsSL https://raw.githubusercontent.com/<USER>/awg-panel/main/deploy/install-panel.sh | bash
```

Скрипт сам: проверит AmneziaWG, клонирует код, создаст venv, сгенерирует случайный
пароль, запустит панель как `systemd`-сервис `awg-panel` и выведет **URL, логин и пароль**.

Либо из клона репозитория:

```bash
git clone https://github.com/<USER>/awg-panel.git && cd awg-panel
bash deploy/install-panel.sh
```

Опции скрипта:

| Опция | По умолчанию | Описание |
|---|---|---|
| `--user NAME` | `admin` | логин панели |
| `--password PASS` | случайный | пароль панели (при повторном запуске сохраняется прежний) |
| `--port N` | `5182` | порт панели |
| `--interface IF` | `awg0` | имя интерфейса AWG |
| `--dir PATH` | `/root/awg-panel` | каталог приложения |
| `--repo URL` | см. скрипт | репозиторий при клонировании |
| `--no-ufw` | — | не открывать порт в UFW |

## Управление вторым сервером (VDS)

### Автоматически, из панели (рекомендуется)

В панели: **Сервер → Управлять серверами → «Развернуть агент на новый VDS»**.
Укажите имя, хост, SSH-пользователя/пароль — панель сама:

1. подключится по SSH (SFTP) и скопирует код агента,
2. установит агент: venv, systemd-сервис `awg-agent` (порт `5183`), случайный Bearer-токен,
3. откроет в UFW удалённого хоста порт `5183` **только для IP панели**,
4. проверит и автоматически добавит сервер в панель.

Ход установки виден пошагово в UI; SSH-пароль используется одноразово и не сохраняется.

### Вручную

```bash
# на центральном сервере: скопировать код и поставить агент по SSH
bash deploy/deploy-agent.sh root@1.2.3.4 <IP_панели> [токен]
```

или вручную на самом VDS:

```bash
# скопируйте каталог проекта на VDS (например, /root/awg-agent) и выполните
bash /root/awg-agent/deploy/install-agent.sh <IP_панели> [токен]
```

`install-agent.sh`: ставит venv, создаёт `/etc/awg-panel/agent-config` с Bearer-токеном
(`600`), запускает сервис `awg-agent` на порту `5183` и в UFW открывает порт только
для IP центральной панели. Если IP панели не указан — порт открывается для всех
(не рекомендуется, ограничьте доступ самостоятельно).

Затем в панели: **Сервер → Управлять серверами → URL + токен** (кнопка «Тест подключения»).
Дальше всё работает через селектор «Сервер» над списком клиентов.

## Структура

```
deploy/install-panel.sh   — установка центральной панели (одной командой)
deploy/install-agent.sh   — установка агента на VDS
deploy/deploy-agent.sh    — деплой агента на VDS по SSH (rsync)
deploy/awg-panel.service  — пример systemd-юнита панели
deploy/agent.service      — пример systemd-юнита агента
core.py                   — общая библиотека операций с AmneziaWG
app.py                    — FastAPI-приложение центральной панели
agent.py                  — FastAPI-приложение агента узла
deployer.py               — авто-деплой агента на VDS по SSH (paramiko/SFTP)
templates/index.html      — веб-интерфейс
```

## Безопасность

- Панель доступна по Basic-авторизации (логин/пароль из `/etc/awg-panel/config`, права `600`)
- Агент доступен только по Bearer-токену (`X-Api-Key`, `/etc/awg-panel/agent-config`, права `600`)
- Секреты не хранятся в репозитории: `state.json` и `servers.json` в `.gitignore`
- Если нужен HTTPS — поставьте панель за reverse proxy (Nginx/Caddy): панель заслуживает
  того, чтобы трафик шёл по TLS, включая HTTP Basic.

## Разработка

```bash
# локальный запуск (панель на :5182)
source venv/bin/activate
uvicorn app:app --host 0.0.0.0 --port 5182

# локальный запуск агента на :5183
AWG_AGENT_TOKEN=testtoken venv/bin/uvicorn agent:app --port 5183
```
